# オカンPay

> テストでがんばったら、その場で給与(ボーナス)が振込まれる。オカンが認める、がんばりの見える化アプリ。

チーム「おかん」

---

## 1. 概要

中高生の子どもを持つ親が抱える「テストのモチベーションが上がらない」「お小遣いを手渡しすると無駄遣いしてしまう」という悩みを解決するLINE Botアプリ。

親がテストの最高点をLINEで送信すると、点数に応じたボーナスが、sunabar(GMOあおぞらネット銀行APIのテスト環境)を通じて子ども専用口座に即時振込される。子どもはLINEで残高を確認することで、がんばりを「見える化」できる。

---

## 2. 解決したい課題

- テストの点数が上がらない。勉強のモチベーションをどう上げればいいか
- お小遣いを手渡しすると、すぐ使ってしまう
- 子どもが自分でお金を管理する習慣が身につかない

---

## 3. アプリの特徴

| 特徴         | 内容                                                                   |
| ------------ | ---------------------------------------------------------------------- |
| 即時性       | 点数を入力したら、数秒で子どもの口座に振込完了                         |
| 見える化     | 子どもがLINEで「残高」と送るだけで、貯まった金額を確認できる           |
| 無駄遣い防止 | お小遣いとは別の「ボーナス専用口座」に貯まる。使う際は親に依頼する想定 |

---

## 4. 登場人物と役割

| 登場人物      | できること                                       |
| ------------- | ------------------------------------------------ |
| 親            | テストの最高点をLINEで送信する                   |
| 子ども        | LINEで「残高」を確認する                         |
| オカンPay Bot | 点数判定・ボーナス金額の計算・即時振込・残高照会 |

---

## 5. 前提条件・スコープ

- 親側は、**教科ごとではなく、その回のテストの最高得点を1回だけ送信する**運用とする(例:「92点」)
- 振込先となる**子ども専用口座は、現時点でsunabar上に未作成。開発開始前に新規作成が必要**
- 振込完了時のLINEスタンプ送信は、本バージョンでは**実装しない**
- 過去の点数履歴を振り返る機能は、**本バージョンでは実装しない**(データベース不要)
- ハッカソンのルールに基づき、本人確認等の厳密な実装は行わない

---

## 6. 機能要件

### 6.1 MUST(必須機能)

#### ① ボーナス判定・即時振込

親が「(数字)点」という形式でLINEに送信すると、点数に応じたボーナス金額を判定し、sunabarの振込APIを使って子ども専用口座に即時振込を行う。

**ボーナス金額テーブル**

| 点数       | ボーナス金額 |
| ---------- | ------------ |
| 100点      | 1,500円      |
| 90点〜99点 | 900円        |
| 80点〜89点 | 800円        |
| 79点以下   | 振込なし     |

**79点以下の場合の返信メッセージ**

```
送金保留!!!お小遣いは自宅待機中です!
```

#### ② 残高確認

子どもが「残高」とLINEに送信すると、sunabarの残高照会APIを使って子ども専用口座の現在の残高を取得し、返信する。

---

### 6.2 ADVANCE(発展機能・時間が余れば実装)

#### ③ 成長段階の表示(ひよこ育成要素)

残高に応じて、キャラクターの成長段階を絵文字で表示する。

| 残高           | ステージ    |
| -------------- | ----------- |
| 0〜999円       | 🥚 卵       |
| 1,000〜2,999円 | 🐣 ひよこ   |
| 3,000〜4,999円 | 🐔 にわとり |
| 5,000円以上    | 👑 王冠     |

ステージが変化した瞬間は、特別な祝福メッセージを追加する。

#### ④ リッチメニュー

LINEのチャット画面下部に、ボタンメニュー(残高確認・使い方など)を設置し、文字入力なしで操作できるようにする。

## 7. システム構成

```
[親のLINE]                [子どものLINE]
     |                          ^
     | 「92点」                  | 残高確認・振込通知
     v                          |
   +----------------------------------+
   |     LINE Messaging API           |
   +----------------------------------+
                  |
                  v (Webhook)
   +----------------------------------+
   |   AWS Lambda (Node.js)           |
   |   - 点数判定                      |
   |   - ボーナス金額計算               |
   |   - 振込API呼び出し                |
   |   - 残高照会API呼び出し            |
   +----------------------------------+
                  |
                  v
   +----------------------------------+
   |  sunabar (GMOあおぞらネット銀行)   |
   |   - 振込API                       |
   |   - 残高照会API                   |
   +----------------------------------+
```

---

## 8. 使用技術

| 技術                | 役割                                          |
| ------------------- | --------------------------------------------- |
| LINE Messaging API  | 親・子どもとのメッセージ送受信                |
| AWS Lambda(Node.js) | 点数判定・金額計算・API呼び出しのロジック実行 |
| sunabar 振込API     | 親の口座 → 子ども専用口座への即時振込         |
| sunabar 残高照会API | 子ども専用口座の残高取得                      |

---

## 9. 処理フロー

### 9.1 ボーナス振込フロー

```
1. 親が「92点」とLINEに送信
2. Lambdaが起動し、メッセージから点数(92)を抽出
3. 点数に応じたボーナス金額を判定(90〜99点 → 900円)
4. sunabarの振込APIを呼び出し、親の口座から子ども専用口座へ900円を振込
5. 振込結果(受付番号など)を取得
6. 親へ「92点!ボーナス900円を即時振込しました」と返信
7. (任意)子どもへ振込完了の通知を送信
```

### 9.2 残高確認フロー

```
1. 子どもが「残高」とLINEに送信
2. Lambdaが起動し、sunabarの残高照会APIを呼び出し
3. 子ども専用口座の残高を取得
4. 子どもへ「現在の残高は◯◯円です」と返信
```
